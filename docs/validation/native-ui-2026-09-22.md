# iOS 原生 UI 重构验收

> 状态：本地验收完成（范围见下文）｜适用：本地 iOS 开发版｜核验：2026-09-23｜依据：本次工作区代码、xcodebuild 与隔离假 API 测试；未提交、未部署

## 行为变化

- 四个入口使用系统标签导航，各自保留导航栈。聊天、照片、播放器使用系统导航和弹窗。
- 系统语义颜色、动态字体与标准控件，保留青色品牌强调色。
- 聊天输入框由系统键盘安全区定位，移除旧标签栏高度补偿和键盘预热。
- 登录、绑定、记忆编辑和设置采用系统表单；添加内容使用系统菜单；重试使用系统确认。
- 日期选择共用 UICalendarView，保留本地日历语义、聊天/回顾标记和照片房间存档入口。
- 去掉粒子 shader、自绘标签滑块、重复装饰动效和按压缩放，加载用系统进度指示。

API、账号身份、同步同意、数据留存及音乐能力开关保持原有业务模型。

### 界面验收

iOS 26.5 的 iPhone 17 Pro、iPad Pro 11-inch (M5)，使用 Debug 假 API 和临时数据。已查看实际截图：浅色聊天与输入区、系统标签栏、带记录标记的日历、照片存档入口、iPad 深色最大辅助字号回顾、最终 iPad 横屏日历。测试实际执行了键盘弹出/收起/再次聚焦、连续发送、照片草稿、失败重试、登录与邮箱绑定、同步同意、日期跳转和存档续聊。

键盘几何回归使用有/无照片草稿的同配置比较；XCTest 的中文键盘 frame 不包含候选词栏，不能把它计作应用留下的空白带。已经移除旧假键盘高度与自绘标签栏尺寸断言。
