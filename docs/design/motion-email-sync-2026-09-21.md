## 已制作

普通版 30 个画面/状态，11 个流程入口：新用户注册、聊天与导航、照片转场、老用户绑定、开启同步、清理与删除、验证码错误、发送失败、同步失败、额度耗尽和按钮按压。主要流程另有 29 个画面的减少动态效果版本；深色参考包含登录、同步说明和同步失败。

保留代码中的纸色、墨色、青色强调、18pt 内容圆角及 26pt 浮层圆角。建立 33 个颜色/尺寸变量和 6 个文字样式。导航胶囊使用四个选中变体；原生 SF Symbols 由 macOS 导出，避免 Figma 字体渲染缺失。

| 交互 | 设计参数 |
| --- | --- |
| 按压 | 按下 120ms、松开 160ms；独立组件演示 |
| 导航 | 280ms ease-out，同一选中胶囊位置变化 |
| 消息 | 220ms ease-out，仅新增消息入场 |
| 照片展开 | 300ms ease-out，同图位置和尺寸连续变化 |
| 弹层 | 220ms ease-out |
| 减少动态效果 | 主要流程统一 120ms DISSOLVE，无空间移动 |
| 键盘、流式滚动 | 待 iOS 实现，使用系统曲线并在真机验收 |

验证码、同步条数、邮件与记录均为预设演示数据，原型不发送邮件、不调用 AI、不清理实际数据。点击输入栏可演示发送，点加号进入已选照片状态。错误和失败可从独立流程入口查看。照片使用 [Tatiana Fernández R 的公开 Unsplash 示例](https://unsplash.com/photos/nPHOH0X6CcQ)，日期与描述不代表照片真实拍摄信息。
