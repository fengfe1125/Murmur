# 产品定位与当前能力

> 状态：现状记录｜适用：iOS、Android、共享后端｜核验：2026-09-13（导航）；其余沿用 2026-08-28｜依据：581b332 MurmurShell、一起听入口；其余依据 PR #14，不代表生产验收

## 产品方向

私人回忆与日记，照片和讲述是素材，AI 是表达与整理的助手。用户确认之后才形成正式留存的日记。
目前仍为邀请制小范围使用，iOS 先定义体验，Android 跟进。2026-09-21 本地开发版增加邮箱注册和历史同步，注册开关默认关闭，尚未部署或正式开放。

## 已有实现与缺口

| 能力 | 当前实现 | 未完成的承诺 |
|---|---|---|
| 聊天 | 照片/文字、SSE、重试、本机 SQLite 长期记录、日期跳转与分页；开发版增加主动开启的历史同步 | 两台真机同步及删除尚待验收 |
| 当年今日 | 同日旧照、随机回落、照片房间、独立按天存档、旧日期续聊 | 没有 AI 成稿确认流程 |
| AI 风格 | 自然友善、以事实和来源为依据；普通聊天、读图、主动消息与整理共用客观回应规则 | 模型表达需持续抽检；没有用户可选风格 |
| 每日回顾与记忆 | 开关内提供每日总结、一个问题、逐条纠正与遗忘、离线缓存 | 尚未部署；不等同于用户确认的日记成稿 |
| 旧私有记忆 | 未启用新版的账号保留既有 dossier 与连续性能力 | 新版账号不混用旧派生记忆 |
| iOS 身份/推送 | 邮箱验证码与绑定开发实现，保留旧邀请接口、App Attest、APNs；每天 50 次账号主动 AI 额度 | 真实邮件、真机签名及端到端验收不能由模拟器测试代替 |
| Android | Debug 注册与交流骨架、构建 CI；后端有 Android 认证/FCM 支持 | 客户端正式认证、推送和体验对齐尚未完成 |
| 运维 | 日志脱敏、余额采样、无正文分类计数、授权创建邀请码 | 生产质量需真实运行观察 |

当前 iOS 四个常驻入口是“聊天、一起听、当年今日、我的”。一起听受服务端房间开关与白名单控制，未开放账号看到“未开放”页；入口存在不代表账号获准使用或功能可公测。日记确认与风格选择仍是未完成的产品方向。

本次工作区新增能力与留存边界见 [日期聊天与每日回顾](../architecture/daily-reviews.md)（2026-09-21，未部署生产）。

邮箱、额度及历史同步的独立开发范围见 [邮箱与同步](../architecture/email-history-sync.md)；邮件域名验证、真机和正式上线仍分开验收。

## 工程事实

- 模型配置默认 DeepSeek 直连；主网关与跨网关降级配置见根目录环境示例。配置支持不代表已接入第二提供商。
- 余额采样可由常驻 worker 驱动，不依赖面板一直打开；质量计数不记录正文。
- 服务端无客户端聊天历史查询接口，不等于服务端不保存任何交流相关信息。
- IM Bot 仅用于隔离测试，代码存在、凭据存在均不构成启动授权。

## 验证口径

代码已存在、CI 通过、真机通过、生产通过是四种不同证据。每次发布在交付记录中附提交与检查链接。
本次重组不连接生产服务，不把历史交接中的“实测”文字升级为当前版本验收。
