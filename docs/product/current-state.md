# 产品定位与当前能力

> 状态：现状记录｜适用：iOS、Android、共享后端｜核验：2026-09-24｜依据：PR #14 代码及本轮产品决策；PR #37 原生聊天与当年今日重构；不代表生产验收

## 产品方向

私人回忆与日记，照片和讲述是素材，AI 是表达与整理的助手。用户确认之后才形成正式留存的日记。
邀请制小范围使用，iOS 先定义体验，Android 跟进；本轮不做公开增长或商业化功能。

## 已有实现与缺口

| 能力 | 当前实现 | 未完成的承诺 |
|---|---|---|
| 聊天 | 照片/文字、SSE、重试；本机记录按页读取、可按日期跳转，保留到用户清空 | 不等同于日记成稿；没有跨设备同步 |
| 当年今日 | 同日旧照左右翻看、随机回落，点“聊聊这张”才进照片房间；独立按天存档（保留到用户清空）、旧日期续聊 | 没有 AI 成稿确认流程 |
| AI 风格 | 当前固定的成熟温柔女性人格 | 没有用户可选风格 |
| 私有记忆 | 交流记录、dossier、可配置的开环与连续性能力 | 没有用户逐条编辑记忆界面 |
| iOS 身份/推送 | 邀请、App Attest、APNs 代码和测试 | 真机签名及端到端验收不能由模拟器测试代替 |
| Android | Debug 注册与交流骨架、构建 CI；后端有 Android 认证/FCM 支持 | 客户端正式认证、推送和体验对齐尚未完成 |
| 运维 | 日志脱敏、余额采样、无正文分类计数、授权创建邀请码 | 生产质量需真实运行观察 |

当前是系统标签栏的四个入口：聊天、一起听（按账号白名单开放）、当年今日、我的。PR #37 把导航与输入栏改为系统组件、
本机记录改存原目录内的 SQLite，没有改变人格运行逻辑。

## 工程事实

- 模型配置默认 DeepSeek 直连；主网关与跨网关降级配置见根目录环境示例。配置支持不代表已接入第二提供商。
- 余额采样可由常驻 worker 驱动，不依赖面板一直打开；质量计数不记录正文。
- 服务端无客户端聊天历史查询接口，不等于服务端不保存任何交流相关信息。
- 本机聊天和照片房间存档不再只留最近 600／6,000 条：保留到用户在设置中清空，删除账号时一并清空这台设备上的两份记录。
- IM Bot 仅用于隔离测试，代码存在、凭据存在均不构成启动授权。

## 验证口径

代码已存在、CI 通过、真机通过、生产通过是四种不同证据。每次发布在交付记录中附提交与检查链接。
本次重组不连接生产服务，不把历史交接中的“实测”文字升级为当前版本验收。
