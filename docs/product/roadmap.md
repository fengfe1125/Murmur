# 后续产品路线

> 状态：提案｜适用：定位落地后的功能开发｜核验：2026-08-28｜依据：用户确认的产品方向

已确定方向，尚未实现；本轮仅整理基础，不将下列功能写成现有能力。

1. **确认后留存的日记。** 从照片与讲述产生候选表达，用户决定保留、修改或放弃。保留原始聊天与照片房间存档的含义，不把旧存档自动转换为已确认成稿。
2. **可选表达风格。** 用户选择 AI 的语气与交流方式，当前固定人格只是其中一个已有实验方向。风格不改变事实，不冒充真人。
3. **iOS 验证后 Android 对齐。** 对齐的是已确认的体验和接口契约，不要求 Android 复制已废弃的 UI。
4. **邀请制体验验收。** 优先可靠上传、失败恢复、数据边界可理解，再评估更广泛分发。

具体日记编辑流程、风格种类、存储/API 设计需在各自功能任务中另行确定；本路线不创建占位接口、空模块或数据库字段。
历史调研只是资料，不自动变成待办；不在本轮新增多角色市场、社交入口或自动日记。
