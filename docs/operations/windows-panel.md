# Windows 管理面板

> 状态：现行规范｜适用：管理员本机｜核验：2026-08-28｜依据：现有面板脚本与重组范围；未进行 Windows 实机验收

先安装 Python 和项目依赖，在仓库根目录保留 `.venv`。配置个人 SSH 别名及 Google Cloud 登录信息，见 [VPS 连接](vps-connection.md)。
运行 `scripts/start-vps-panel.bat` 可启动本机面板。原启动器仍含既有主机默认值，本轮不擅自替换实际运行配置；通用配置以本机 SSH 别名和环境变量为准。

面板默认绑定 `127.0.0.1:8765`，不在 VPS 新开管理端口。查状态是读取；创建邀请码是生产写操作，需要授权。
余额快照也会写本机数据库；不要把面板描述成完全只读。

仓库不保存真实 SSH 账号、私钥、访问 token 或新生成的邀请码。检查日志时先脱敏。
