# 日期聊天与每日回顾

> 状态：现状记录｜适用：iOS 与共享服务端｜核验：2026-09-21｜依据：本次工作区实现，未部署生产

## 用户行为

首页仍为聊天，四个 Tab 不变。日期标题跟随正在阅读的消息，日历定位当天第一条本机消息；只有服务端回顾的日期可直接打开回顾，并提示原始聊天不在本机。回顾按总结、一个问题、长期记忆排列。回答问题进入首页输入框，提交时携带问题日期，按实际发送日期保存回答。

自动整理默认当地 22:30，可关闭或修改时间。只显示 App 内入口和未读版本标记，不新增推送。首次启用从当天开始，不补历史；无有效交流不生成。22:30 后的新内容更新同一份回顾，问题保持首次发布的版本。涉及“忘记”的问题会被撤回，以免继续显示已撤销的事实；剩余来源可重新生成问题。

## 本机存储

首页仍使用 `Application Support/Murmur`，照片房间仍使用其 `archive` 子目录。各自的 `transcript.sqlite` 保存消息，图片仍在各自 `images` 目录。SQLite 使用 WAL、FULL 同步及完整文件保护。消息 ID、发送时间、逻辑归属日期、发送状态、moment ID、幂等键、每日问题日期和附件引用保留。

旧 `transcript.json` 在单个事务中导入，逐条比较内容成功后写入迁移标记；失败回滚，保留原文件供重试。JSON 仅包含当时仍存在的记录，不恢复已丢失内容。迁移文件直到明确清空才删除，数据库迁移标记防止重新导入。

按时间与稳定插入顺序分页，每页默认 100 条，阅读窗口最多 400 条。相同时间戳不会按随机 UUID 颠倒顺序。取消旧的 600/6,000 条留存裁剪。保存一个窗口只更新其中的记录，不删除窗口之外的历史。只有明确删除或清空时清理无引用附件；保存失败在界面显示，失败的写入和图片保留供重试。

## 服务端任务与时间

服务端开关 `MURMUR_DAILY_REVIEWS_ENABLED=1`，默认关闭。App 根据认证后的 `/v1/reviews/config` 判断可用性，首次可用时保存默认偏好；旧客户端不需要调用新接口。

新增表位于原 App 数据库中，不移动生产数据。常驻 worker 在独立线程和独立数据库连接中运行每日任务，不占用聊天领取通道。任务持久化在每日回顾行中，按账号和日期唯一；领取使用 10 分钟租约，失败指数退避，重启后扫描启用以来的已完成交流补齐任务。

来源仅从持久化且 `complete` 的入站 moment 及其 committed Memory 记录导入。未发草稿、失败请求、未发相册照片不参与；AI 的回复不能当作用户表述。交流创建时记录最近活跃设备的时区，据此固定交流归属日；照片拍摄日期单独保存。调度按最近活跃设备的当前时区计算当地生成时间，并保存生成使用的时区。改变时区不会把已经归档的交流重复挪到另一日。

内容指纹避免无变化重复生成；更新后的来源进入下一版本。租约与账号偏好修订号共同阻止过期任务覆盖纠正、关闭设置或账户删除。无来源时不让模型编造内容。日志仅输出任务状态、重试及异常类型。

## 记忆与删除

每条记忆标注 `user_stated`、`image_observed` 或 `uncertain`，关联来源 ID、交流日期及必要来源摘录。人工纠正不被自动生成覆盖；模型读取纠正后的表述，用户仍能看到原始来源。相关性召回最多 8 条，日期及来源随条目进入上下文。

遗忘添加来源排除记录，撤销依赖同一来源的记忆，并立即清空相关派生总结与问题。重新生成只用允许的来源，不会重新导入被排除的原记录。原始聊天不删除。纠正或遗忘后，模型历史读取还会过滤对应来源；无法逐项追踪来源的旧 AI 回复不再进入上下文。新版记忆用户不再混入旧 dossier、开环与情绪状态，避免旧派生文本恢复已撤销事实。

回顾缓存按账号散列目录保存，每日一个文件，只加载当前详情。纠正或遗忘成功后移除旧派生缓存；退出本机身份或删除账户清除此账号的回顾缓存。服务端新表均随账号级联删除，后台发布前复核账号状态。原始聊天同步、原图云备份、导出及用户确认的正式日记成稿不在本次实现范围。

## 接口

全部新增数据接口沿用现有请求认证；SSE 事件格式不变。

| 接口 | 用途 |
|---|---|
| `GET /v1/reviews/config` | 能力开关和当前偏好 |
| `PATCH /v1/reviews/preferences` | `enabled`、`local_time` |
| `GET /v1/reviews?before=YYYY-MM-DD` | 倒序日期、状态、版本；每页最多 90 天 |
| `GET /v1/reviews/{day}` | 总结、问题、记忆及其来源摘录 |
| `POST /v1/reviews/{day}/refresh` | 请求重整，JSON `{}`；空日返回 `empty` |
| `PATCH /v1/review-memories/{id}` | `text` 纠正，1–500 字 |
| `DELETE /v1/review-memories/{id}` | 幂等遗忘，不删除原始聊天 |
| `POST /v1/moments` 的 `daily_question_day` | 可选 multipart 字段；由服务端核对本账号问题并保存上下文 |
