# 数据生命周期

> 状态：现状记录｜适用：App、后端、模型调用｜核验：2026-08-28｜依据：PR #14 中客户端存储、app_store、app_worker、memory 代码

| 数据 | 处理与留存 | 边界 |
|---|---|---|
| 本机相册 | 用户授权后在设备浏览；由用户选择发送照片 | 浏览不等于整库上传 |
| 临时上传原图 | App 建立临时文件，API 暂存并交给 worker；终态清理 | 不能宣称“原图从不上服务端” |
| 模型输入 | 压缩图和必要文字上下文 | 不是离线推理，也不是端到端加密 |
| 聊天记录 | 设备端持久化，冷启动恢复 | 不混入照片房间存档 |
| 照片房间存档 | 设备端独立存档，按交流归属日期组织 | 不是用户确认的日记成稿 |
| 服务端记忆 | 交流相关记录、dossier、压缩预览及上下文关联 | 无历史查询接口不代表无服务端留存 |
| 作业与 SSE 事件 | 服务端短期处理、续传与重试；按既有清理策略过期 | 已完成任务清理输入正文，事件默认有 TTL |
| 地点 | 精确位置可被瞬时读取，转换为匿名地点指纹 | 不把原始 GPS 坐标传给模型，不解析成地名 |
| 歌曲卡片 | 只有 TrackV1 元数据快照：provider、track_id、标题、艺人、封面、官方链接、时长 | 不含令牌、stream/CDN 地址、歌词或音频；每次播放按 track_id 重新核验 |
| Audius 授权 | access/refresh token 只存本机 Keychain（`AfterFirstUnlockThisDeviceOnly`）；断开或 Murmur 身份变化即清除 | 不上传服务端，服务端也不代持用户身份 |
| 播放状态 | 只有离散转换（started/paused/resumed/completed/stopped）与曲目最小字段；按状态给 TTL，过期即删 | 不是进度、音量、设备路由或收听历史；只进当前模型上下文，不入长期记忆或画像 |
| 曲库查询 | 服务端用自己的应用 key 查公开元数据；命中缓存 6 小时、不可用负缓存 5 分钟、查询结果仅进程内 5 分钟 | 查询词、标题、艺人、track id 与 URL 都不写日志 |
| 一起听动作记录 | 聊天点歌触发房间动作时，在对应 `app_moments` 行长期保存歌曲元数据、create/play_track、目标房间 handle、幂等键、结果状态和固定说明；随账户级联删除 | 这是防止任务重试重复建房或换错歌的副作用记录，不含网易账号、Cookie、外部房间 ID、协议序号或音频 |
| 运维数据 | 余额快照、无正文分类计数、脱敏日志 | 面板仍可访问敏感业务记录，只应对管理员开放 |

## 清理不是同一件事

设备端“清空聊天”与“清空当年今日存档”是两个操作；不能文档化为删除服务端全部记忆。
账户删除走现有服务端擦除流程；播放状态随 app_users 级联删除，Audius 令牌由客户端在
身份消失时自行清除——服务端从来就没有它。未来日记的保留、导出和删除能力尚未实现，不提前承诺。

## 重组约束

仓库源码移动不移动或重建生产数据库、照片、dossier、日志及密钥。
根目录运行环境和进程 cwd 保持不变；已有相对配置必须仍指向原位置。
本地配置随客户端工程保全，内容不入 Git；版本控制只包含配置示例。


## 2026-09-23 本机分页增量

聊天和照片房间仍在各自原目录内，JSON 首次读取校验后迁移到 SQLite。页面窗口不再等于保存数量：窗口外记录保留至用户清空，本机图片继续使用完整文件保护。此客户端增量不增加云端历史同步。每日回顾缓存按用户隔离；服务端能力未开放时不进入回顾流程。
