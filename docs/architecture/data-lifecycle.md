# 数据生命周期

> 状态：现状记录｜适用：App、后端、模型调用｜核验：2026-08-28｜依据：PR #14 中客户端存储、app_store、app_worker、memory 代码

| 数据 | 处理与留存 | 边界 |
|---|---|---|
| 本机相册 | 用户授权后在设备浏览；由用户选择发送照片 | 浏览不等于整库上传 |
| 临时上传原图 | App 建立临时文件，API 暂存并交给 worker；终态清理 | 不能宣称“原图从不上服务端” |
| 模型输入 | 压缩图和必要文字上下文 | 不是离线推理，也不是端到端加密 |
| 聊天记录 | 设备端持久化，冷启动恢复 | 不混入照片房间存档 |
| 照片房间存档 | 设备端独立存档，按交流归属日期组织 | 不是用户确认的日记成稿 |
| 服务端记忆 | 交流相关记录、dossier、压缩预览及上下文关联 | 无历史查询接口不代表无服务端留存 |
| 作业与 SSE 事件 | 服务端短期处理、续传与重试；按既有清理策略过期 | 已完成任务清理输入正文，事件默认有 TTL |
| 地点 | 精确位置可被瞬时读取，转换为匿名地点指纹 | 不把原始 GPS 坐标传给模型，不解析成地名 |
| 运维数据 | 余额快照、无正文分类计数、脱敏日志 | 面板仍可访问敏感业务记录，只应对管理员开放 |

## 清理不是同一件事

设备端“清空聊天”与“清空当年今日存档”是两个操作；不能文档化为删除服务端全部记忆。
账户删除走现有服务端擦除流程。未来日记的保留、导出和删除能力尚未实现，不提前承诺。

## 重组约束

仓库源码移动不移动或重建生产数据库、照片、dossier、日志及密钥。
根目录运行环境和进程 cwd 保持不变；已有相对配置必须仍指向原位置。
本地配置随客户端工程保全，内容不入 Git；版本控制只包含配置示例。
